# Architecture Decision Records

This directory holds Jacer's architecture decision records (ADRs): short documents
capturing a significant decision, its context, and its consequences. They are the
project's standalone decision history — newer ADRs may supersede older ones.

| ADR | Title | Status |
|---|---|---|
| [ADR-001](ADR-001-mit-licence.md) | MIT licence | Accepted |
| [ADR-002](ADR-002-original-stack.md) | Original v2 stack (FastAPI + React) | Superseded (frontend) by ADR-003 |
| [ADR-003](ADR-003-blazor-mudblazor-frontend.md) | Blazor + MudBlazor frontend | Accepted |

## Format

Each record follows a light template: **Status**, **Date**, **Context**,
**Decision**, **Consequences**. Keep them short — a decision and its reasoning,
not a design document.

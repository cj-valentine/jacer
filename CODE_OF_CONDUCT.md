# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its Code of Conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — opening issues, commenting on PRs, contributing code or docs — you agree to abide by it.

## Reporting

If you experience or witness behaviour that violates the Code of Conduct, please report it to the project maintainer at the email address listed on the maintainer's GitHub profile. Reports will be handled confidentially.
